# Roadmap

## Fase 1 — Fundación (actual)

- API Django/DRF modular.
- Contrato JSON Schema para briefs.
- Modelos de catálogo, campañas, diseños, activos y validaciones.
- Interfaz de proveedor IA con adaptador OpenAI.
- Health check, pruebas y CI.

## Fase 2 — Composición controlada

- Biblioteca de plantillas HTML/SVG versionadas.
- Renderizador de formatos 1080 px y previsualización.
- Verificación automática de zona de seguridad, legibilidad y campos críticos.

## Fase 3 — Revisión y operación

- Autenticación corporativa y roles.
- Flujo de revisión/aprobación con comentarios.
- Historial visible y exportación para redes/WhatsApp.

## Fase 4 — Inteligencia aplicada

- Generación de copy basada exclusivamente en datos autorizados.
- Evaluación de calidad y trazabilidad de prompts/respuestas.
- Segundo proveedor compatible con la interfaz, solo después de validar necesidades.
