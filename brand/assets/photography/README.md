# Fotografía — International House México

Esta carpeta está preparada para recibir fotografía oficial/autorizada por pilar de negocio.
No se encontraron archivos de fotografía de stock oficial entre los documentos analizados —
solo las reglas de estilo fotográfico, documentadas en
`brand/documentation/imagery-rules.md`.

Al recibir fotografía oficial, organizar en subcarpetas por pilar:

```
photography/
├── ingles-general/
├── cambridge/
├── university-programmes/
├── empresas/
├── ielts/
└── spanish-courses/
```

Cada imagen debe cumplir (ver `imagery-rules.md` para el detalle completo):
- Resolución mínima 1920×1080px (hero: 2560×1440px).
- Formato preferido WebP con fallback JPEG, máximo 200KB optimizado.
- Personas reales en interacción genuina, diversidad de edad/género/origen — nunca posadas ni de stock genérico.
- Sin efecto duotono.
