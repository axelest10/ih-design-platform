# Identidad visual de Hello Live English

Estado: identidad independiente adoptada formalmente por Axel Estrada el 2026-08-09. Aplica a la
marca **hello**, su producto **Live English** y la sub-variante **Live English Kids**.

## Paleta

Fuente: `brand/assets/logos/sub-brands/hello-live/Brandfolder-Hello Live English.pdf`, página
“Paleta de color”.

| Color | HEX |
| --- | --- |
| Navy | `#0B1D3A` |
| Azul | `#1565FF` |
| Cian | `#00C2C7` |
| Verde | `#22C55E` |
| Naranja | `#FF9F1C` |
| Magenta | `#FF2DBD` |
| Morado | `#7B2CBF` |
| Blanco claro | `#F2F4F7` |

Los códigos sueltos `#f4a261`, `#c4c4c4`, `#ef642e` y `#000000` no se adoptan: no tienen nombre
ni corresponden visualmente con los ocho swatches documentados y se identificaron como texto de
plantilla de Canva sin editar. La fuente de esta exclusión es la misma página del Brandfolder.

## Tipografía

Fuente: `Brandfolder-Hello Live English.pdf`, página “Tipografía”, y
`brand/assets/fonts/poppins/OFL.txt`.

- Poppins Bold: logotipo y títulos.
- Poppins Regular: textos de soporte.
- Descriptor: “Moderna, amigable y clara. Transmite confianza, cercanía y profesionalismo.”
- Licencia: SIL Open Font License 1.1, copyright “The Poppins Project Authors”.

## Iconografía

Fuente: `Brandfolder-Hello Live English.pdf`, página “Iconografía”. El estilo es lineart de línea
fina en navy (`#0B1D3A`), con puntos decorativos en magenta y naranja.

1. **Conversación real:** dos globos de chat superpuestos.
2. **Profesores certificados:** persona con insignia o estrella.
3. **Clases en vivo por videollamada:** monitor con persona.
4. **Corrección en vivo:** documento con lápiz.
5. **Progreso real:** gráfica de barras ascendente con flecha.
6. **Comunidad cercana:** grupo de personas con corazón.

## Estilo visual

Fuente: `Brandfolder-Hello Live English.pdf`, página “Estilo visual”.

- Fondos navy oscuro (`#0B1D3A`) con fotografía real de personas usando auriculares, laptops o
  videollamadas.
- Overlays circulares con gradiente naranja → magenta → morado → azul, replicando los colores
  del isotipo.
- Titulares blancos en Poppins Bold, con una palabra clave resaltada mediante color de acento o
  gradiente.
- CTAs en forma de píldora (`rounded-full`), con fondo sólido cian/naranja o navy oscuro y texto
  blanco.
- Para historias existe una variante de fondo con gradiente diagonal completo naranja → magenta
  → morado → cian; sobre ella se usa el isotipo blanco en outline, no el isotipo a color.

## Alcance

Fuente: adopción confirmada por Axel Estrada el 2026-08-09 a partir del Brandfolder citado.

Esta identidad aplica exclusivamente a materiales propios de Hello Live English y Live English
Kids —incluidos su web, redes sociales y anuncios—. No sustituye el sistema institucional de IH
México: cuando “Hello!” identifica el pilar Inglés General dentro de una pieza institucional de
IH, se mantiene Youth Green según `brand/product-colors/authorized-colors.yaml`.
