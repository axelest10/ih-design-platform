# Operaciones

- [`deployment.md`](deployment.md): preparación de staging, variables requeridas y comparativo de
  proveedores.
- [`email.md`](email.md): Postmark, remitente aprobado, seguridad por entorno, pruebas, rotación y
  rollback del correo transaccional.
- [`approval-flow.md`](approval-flow.md): recomendación para retirar gradualmente el endpoint
  legacy de aprobación.

No existe todavía un runbook de incidentes, monitoreo o backups de aplicación porque no hay un
entorno desplegado sobre el cual verificar esos procedimientos.
